# VNode 架构演示

## 说明

这是一个展示 VNode 架构（Plan 012 Phase 1-2）的演示程序。

## 功能

- ✅ 直接创建 VTree
- ✅ 渲染各种 VNodeKind
- ✅ 左侧显示树结构
- ✅ 右侧显示渲染结果

## 运行

```bash
cd examples/vnode-demo
cargo run
```

## 展示的控件

- Text - 文本显示
- Button - 按钮
- Input - 输入框
- Checkbox - 复选框
- Radio - 单选框
- Slider - 滑块
- ProgressBar - 进度条
- List - 列表
- Table - 表格
- Column/Row - 布局
- Container - 容器
