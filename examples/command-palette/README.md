# Command palette settings example

Open the command palette and search for `theme`. Run **Dark theme** or **Light theme** to update the page's theme. Reopen the palette to run **Theme settings** or search with the Chinese keyword `外观`. **Open file** demonstrates an application rejection. The two **Reset settings** commands have separate IDs and search keywords. The organization-managed setting is disabled.

On Windows, use `auto run -r vm` for the Native VM window or `auto run -r vue` for the Vue frontend from this directory.
