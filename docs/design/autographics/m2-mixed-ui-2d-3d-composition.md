## 1. 目标与里程碑身份

M2除原M2-01..09外，明确增加**M2-10：一个真实Auto应用用Node/use/model/msg/on与view/view-2d/view-3d，组合基础UI、二维和三维呈现；UI事件改变Auto状态并影响两种场景，场景逻辑也能改变UI；布局、输入、实例状态、生命周期与独立离线消费成立。** 不能用三个独立进程/窗口拼接、Rust业务按钮、仅HUD字形或旧原型截图代替。

原九项、G2九项/G3八项、Gallery12逻辑项/22入口/47变体及原预算继续保持。AG019已交付`3daf2eb`，引擎候选`fc82061cd12a77b8422c4d4b47d5862ee9af7b37`，SDK681；其最终收据称“原合同边界内本地候选就绪，不称M2完成”。不重开、不改其归档或canonical、不追加019任务。新M2-10缺口用048→049→AG021补齐；最终是否满足M2还须原九项及所有具名必需门对账，不以新示例绿覆盖旧OS/来源缺口。

## 3. 最小明确支持面

- UI基础集：`row`、`column`、`text`、`button`；复用已有AutoUI属性/事件约定，补Node普通`view`，支持局部model/msg/on、普通use、两个同定义实例隔离、条件呈现、按钮事件与文字/可用态绑定。静态UTF-8文字至少覆盖中文；动态整数/布尔状态可通过普通Auto helper格式化。不把四槽ASCII HUD上限偷当UI语义，也不承诺整个生产组件库。
- UI容器中的`view-2d`/`view-3d`是**同时呈现的嵌入区域**，不是互斥变体分支。根UI view可通过row/column容纳两者，纯二维/三维Node仍直接写view-2d/view-3d，无强制额外view壳。嵌入复用独立Node/模块，实例边界不等于文件边界。
- 一个应用/原生窗口内同时显示UI控件、真实二维图元/场景和真实三维几何/相机。首期为平面布局嵌入，不要求把任意UI采样到3D曲面/任意网格、全套三维UI遮挡或跨窗口。嵌入区域尺寸/布局变化会真实改变viewport/裁剪/输入映射，不能靠预录图片/外部窗口。
- 所有业务状态和事件处理由真实Auto执行。Rust仅做编译、平台控件/渲染、调度/输入与协议适配。一个状态owner不因多个出口/挂载重复初始化或Tick；不预先强制单文件/单模块/单VM。普通组件引用沿既有props/msg显式边界，不按同名字段自动共享，不增加逐字段冗余转接来破坏同Node局部性。
- 输入按命中区域/焦点/捕获路由；UI按钮消费的点击/键盘激活不能漏到游戏区域；窗口失焦/卸载取消捕获，事件要绑定实际实例和Run代次。布局中同样的组件分别维护实例状态，渲染重建不重启业务。
- 原Life.Start/Tick语义沿用；Life.Frame、环境多呈现选择、完整主题/复杂文本编辑/IME、ACE/AOT/HMR/ECS/CPC、跨端均不在本补齐范围。按钮鼠标与键盘激活及Tab焦点属基础UI必需验收，不能以这条排除。

## 4. 端到端机制与预算决定门

复用共享语言表达式/ModelBlock/MsgDecl、既有ViewNode/事件语法和AGP SurfaceRuntime。048补普通UI Node的版本化产物/真实Auto事件桥；049补嵌入AST/布局目标、图形内容adapter、一次更新的状态owner及输入路由。当前布局/控件可使用真实stock Iced作为原生后端，但按钮业务必须由作者Auto on处理，不能继续复制PauseUi业务。

两份引擎计划各有T-02：最多两种等价机制的完整最小链先证，并冻结声明拼写、产物/API身份、源闭包/SDK与队列/字符串/资源支持表。UI事件到固定SDK调用只支持标量现状，文字需通过已证的有界协议/序列读取等价方式传递，不能凭空把Session当支持String；不能偷偷换SDK或把tip/pinned语言包并进同一Cargo图。049须先证“真实按钮→Auto状态→二维位置/三维姿态＋UI文字→真实GPU”，不能只证明解析或离屏静态图。

原32credits/回调、物理写32、有状态Node8、场景行128及旧深度/资源/VM预算保持；同一逻辑owner的模块/出口不各得一池。T-02给出owner→运行世界→VM→服务费用映射，新增UI布局/事件队列/UTF-8传输另做有界支持和实测记账，不冒用GPU RSS充资源owner或给无限队列。用例规模是验收覆盖而非擅自定义新的语言全局上限；必要容量策略在T-02可审阅冻结，不能静默抬旧预算。证明不了则具名needs_replan，不以Rust业务/隔帧停逻辑/删事件换绿。

失败按关联域处理：编译/资源准入失败保最后可用应用；无效新图/结构保旧图；普通业务局部失败不天然否定整个世界。根VM故障、设备故障等相关域可停止，必须有明示错误/恢复；重载/新Run屏蔽陈旧点击。布局图的准备/提交原子性不作为禁止use或全游戏事务的理由。

## 6. 完成判据

新app的UI按钮能改变两种场景并反馈状态；分别对2D/3D局部输入能反馈UI，同一计数不会因两视图重复Tick；两个同定义组件状态隔离；布局重排/窗口resize/边界裁剪与键盘焦点正确；隐藏/卸载/Stop/新Run不串事件/泄漏，真实冷A→B离线修改源码再生可见变化；正例/故障控制/恢复下一次实际Run和独立final齐。原M2-01..09与具名必需门另逐条核，不以新示例代两完整游戏或Gallery；未关闭的OS/历史来源问题按原结论保留。当前只是目标与计划，048/049/021均drafting/r1/0-10，未新建树/材料scope/探针或运行任何新UI/GPU链。
