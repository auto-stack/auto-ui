# PLAN-106 AutoUI U04 服务与数据应用 AV 与 A2Vue 交付

## 0. 变更摘要

2026-11-19 按用户裁定建立独立交付计划。承接语言 980 B-AV、1071 冻结清单中 U04 的原示例和关联 Widgets，验收 ACE AV 桌面和 A2Vue 浏览器。由本计划负责 AutoUI 和所需 AutoLang 改动，并补齐这些应用实际用到的缺失组件。A2R、AC 由后续独立计划接同源验收。本次为规划，进度 0/8。

## 1. 目标

以下 6 个原项目及关联 Widgets 各有两端可复跑结果。复用原 `pac.at`、作者源、依赖及独立预期。交付可从干净目录构建和运行的项目、固定工具与 SDK 版本、每端操作记录及独立复审结论。

| AutoUI 原例 | 两端项目级检查重点 |
|---|---|
| [014-weather](../../examples/ui/014-weather/pac.at) | 固定真实服务输入、加载/失败/重试及可见数据 |
| [017-chat](../../examples/ui/017-chat/pac.at) | 真实消息端点、异步返回、取消或断连后的恢复 |
| [023-realworld](../../examples/ui/023-realworld/pac.at) | 真实业务接口、列表/详情、失败码与重新加载 |
| [025-sys-monitor](../../examples/ui/025-sys-monitor/pac.at) | 由实际服务采集并刷新数据，权限受限时给出诊断 |
| [026-database](../../examples/ui/026-database/pac.at) | 对真实数据库读写、事务或失败响应与资源回收 |
| [027-file-manager](../../examples/ui/027-file-manager/pac.at) | 真实文件树导航、原操作、权限拒绝和视图更新 |

关联 Widgets 使用 [AutoOS 规范来源](../../../auto-os/widgets-gallery/src/front/) 的 pages 与实际 components 闭包。datatable、filetree、treeview、table。T-01 把 1071 标识逐项对应到实际页、组件与原测试，给复用页记录版本和各组消费结果。

## 2. 架构与跨仓职责

- **AutoUI 主责。** 负责示例、组件契约、Iced 宿主消费、Vue 生成产物及真实交互。可复现服务以真实协议和实际存储运行，测试数据可隔离，核真实请求/结果和失败路径。AV 经既有授权宿主调用，Vue 按真实浏览器接口或已授权服务桥接，校验权限收敛、取消后无旧回写、关闭释放。共享表格及文件树沿既有组件接线，核 085 等已交组件的范围与缺口并交真实应用证据。
- **AutoLang 为同一计划的实施仓。** 核定原项目的异步、网络、文件、数据库、标准库与错误传播调用，绑定现有受检模块、AV 能力授权、A2TS 端口和类型映射。若触及领域共享实现，由本计划修所需的 AutoLang 接线及永久反例，服务端口按对应协议/宿主职责实现。对实际使用的返回值、取消和错误映射做跨端对照。 相关改动在组内 AutoLang 树完成，沿原模块 owner 审查与合入。
- **真实组件。** 对本组使用的每个缺失组件或缺失行为，优先补已有组件，再补所需新组件。交付适用属性、事件、绑定、生命周期和无障碍行为，两端实现、永久回归及原项目调用都计入本计划的完成条件。已有其他计划在写同一组件时，先对账实际界面与写面，固定单一实施负责人，当前计划持有本消费者验证及关闭条件。

## 3. 技术与实现入口

AV 沿 `crates/auto-ui-runtime/src/ui/ace_node_desktop.rs` 的公开宿主路径、受检 AGE Schema 和 typed 事件。A2Vue 沿 `crates/auto-ui-runtime/src/ui/ace_vue_script.rs`、`ace_ts_provider.rs`、`ace_package_sfc.rs` 和正式 `auto-ui-tools` 入口，验生成的 Vue/TS、运行时与资源。AutoLang 优先复用已有 AGE/ACE、AV 和 A2TS 管线。Windows AV 及所选浏览器配置各有实测记录，其他原适用平台按冻结的运行条件记账。
