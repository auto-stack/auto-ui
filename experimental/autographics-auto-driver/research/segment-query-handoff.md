The Play native verifier treats the existing backlog/display-gap automatic pause
as an observable runtime state. In live input phases it resumes through the
actual OS/Iced Resume button, restores the original input target and re-posts
only an unaccepted V batch. Accepted toggle reports prevent double application.
Motion still requires at least5 real2D and90 real3D actions, and every original
pixel/reference/Step/focus-loss/Stop assertion remains. Phase deadlines never
restart; Fault and explicit Step/focus policies are not bypassed. Runtime clock,
credits, CPU limits and production input routing are unchanged.

`python tools/check_play_clock_pause.py <new-directory>` injects a real100ms
event-loop stall before motion, hide and restore inputs, then runs the original
OS/Auto/GPU oracle. A copied verifier with recovery removed must fail within the
original deadline. This script builds test-only entry copies, never edits the
producer implementation or changes runtime limits.
