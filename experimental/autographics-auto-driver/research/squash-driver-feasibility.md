Selected approach: real Auto f32 gameplay/math plus an explicitly requested, ordered raw seeded xorshift64* host service. Auto decides spawn timing, position, jitter, speed, target, collisions, score and stop/death. Host never calls SquashDriver in Auto mode. Each requested value has an instance/session and monotonic ordinal; the host clones the RNG candidate and commits it only after Auto accepts that ordinal. Rejected/duplicate/out-of-order values do not advance the accepted stream; reset creates a fresh session, RNG and ordinal. A failed script is closed, never continued from partially modified state; its last accepted packet remains visible.
